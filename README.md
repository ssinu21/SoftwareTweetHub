# SoftwareTweetHub

SoftwareTweetHub is a full-stack social posting application where users can register, log in, create posts, view posts, and delete posts.

## Features

- User registration
- User login
- Create posts
- View all posts
- Delete posts
- MySQL database integration
- React frontend
- Spring Boot REST API

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- React JS
- HTML
- CSS
- JavaScript
- Git & GitHub
